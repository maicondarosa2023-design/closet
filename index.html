📒 Gerador de Catálogo

Cadastre produtos e preços, deixe a IA escrever os textos e baixe o catálogo em PDF.

⚙️ IA gratuita (configurar)

Os botões ✨ usam uma API de IA com plano gratuito. Gemini e Groq pedem uma chave gratuita, que fica salva só neste navegador.

1. Sua loja

2. Cadastrar produto

3. Produtos (0/100)

4. Enviar para grupos do WhatsApp

O PDF vai como documento, um grupo por vez, com pausa de alguns segundos entre os envios.

Como o envio funciona

Este site não tem servidor próprio. Para enviar o PDF aos grupos automaticamente, aponte para um servidor seu (n8n, Make, Evolution API etc.) que receba o arquivo e envie pelo WhatsApp. Sem servidor, use “Compartilhar pelo celular” e escolha o grupo na mão.

Este QR abre o painel do seu servidor no celular. O QR de pareamento do WhatsApp é gerado por esse painel.
